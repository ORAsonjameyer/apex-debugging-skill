# Workspace Evidence Intake

Before a substantive Workspace check, ask once whether the user has the relevant Workspace Monitor Activity report, active-session status, schema-mapping details, or Workspace administration screenshot. Ask for the report time window and Workspace name when missing.

Use `workspace/references/diagnostics/workspace-protocol.md` for protocol and output-location rules. Keep evidence outside this repository and share only redacted excerpts.

Live reproduction and browser-level evidence for an APEX application use `workspace/references/diagnostics/live-browser-debugging.md`. Application source/component diagnosis and APEX Debug/Trace evidence belong to APEXlang. Generic database, AWR/ASH, SQL Monitor, ORDS, and infrastructure analysis belongs to the DB skill. Do not request or analyze those evidence types as part of Workspace evidence intake.
