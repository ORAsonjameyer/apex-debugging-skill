# Repository guidance

- When introducing or materially changing a skill capability, workflow, safety boundary, or handoff, update the current cheat sheet in the same change. Keep its Markdown and visual one-pager consistent with the actual skill and its ownership boundaries.
- Keep the current cheat sheet embedded in the `What It Provides` section of `README.md`, immediately before `Scope Boundaries`, with a compact preview linking to the full-size image on the left and the capability list on the right. When publishing a new version, update the README and the cheat sheet's own links to the current files.
- If the visual one-pager cannot be updated, state that limitation explicitly and do not present an outdated image as current.
